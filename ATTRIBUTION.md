# Attribution

This dataset is a compilation. The original compilation work (parsing the
official ÖSYM/DGS guides into the catalogue and DGS transfer map; unifying the
yearly statistics; and this packaging) is released under CC BY 4.0. The upstream data components retain their own terms, listed below.

## Underlying source

All admission statistics ultimately derive from **YÖK Atlas**
(https://yokatlas.yok.gov.tr) and **ÖSYM** (https://www.osym.gov.tr), the
official Turkish higher-education data providers. These are public data.
